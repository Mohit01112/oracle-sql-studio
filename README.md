# Oracle SQL Studio

An offline-first desktop application for learning and practicing Oracle SQL.

## Features

- Interactive Oracle SQL lessons
- SQL editor and query execution
- Practice questions with hints
- Interview preparation
- Student progress tracking
- Local database support
- Offline learning

## Tech Stack

- Python
- PySide6
- Oracle Database
- SQLite
- python-oracledb
